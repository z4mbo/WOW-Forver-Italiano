# WOW Forver - Italiano

WOW Forver - Italiano is a free and open-source addon for the World of Warcraft: Forever beta (interface 16001). It brings verified in-game text into Italian and works entirely offline.

Version 0.3.0-beta translates interface elements, character panels, reputation, abilities, guild, collections, settings, professions, and Edit Mode. It also includes quests, items, spells, and NPC names identified by their IDs and the client's original text. Among other things, we verified the in-game description for Eviscerate, the Undead racial ability Will of the Forsaken, and the target name Wretched Zombie.

The translation is still partial: the beta client does not contain all Italian text, and many quests and NPC lines come from the server. New content, some descriptions, and parts of the interface may therefore remain in English. The addon does not translate voice acting, cinematics, player chat, or third-party addons.

## Installation

Extract the `WOWForverItaliano` folder from the ZIP into `World of Warcraft/_classic_beta_/Interface/AddOns/`, enable the addon, and type `/wfi status`. On CurseForge, enable the Beta filter if the file does not appear in the default list.

## Code and contributions

The [source code](https://github.com/z4mbo/WOW-Forver-Italiano) is available under the MIT License. To report missing text, include the exact English phrase, the build, and, if available, the quest, item, spell, or NPC ID along with a screenshot.
